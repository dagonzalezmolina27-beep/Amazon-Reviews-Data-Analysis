# Amazon Reviews Data Analysis

Proyecto académico de Ciencia de Datos desarrollado en un equipo multidisciplinario de cinco integrantes, orientado al análisis de reseñas de productos de Amazon.

El proyecto integró diferentes áreas de trabajo, incluyendo ingeniería de datos, ciencia de datos, visualización en Power BI y gestión del proyecto.

## Mi participación

Mi rol se centró en el área de **Ciencia de Datos**, trabajando principalmente en:

- Análisis exploratorio de datos (EDA).
- Análisis de variables relacionadas con calificaciones, votos útiles y características de las reseñas.
- Análisis de reputación de marcas por categoría.
- Preparación y transformación de datos.
- Análisis de sentimiento de las reseñas.
- Selección de características para el modelado.
- Desarrollo y evaluación de modelos de Machine Learning utilizando Random Forest.

## Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- TextBlob
- SQL
- Jupyter Notebook

## Machine Learning

Se utilizó **Random Forest** como modelo de Machine Learning, realizando diferentes iteraciones y evaluando distintas características para analizar su comportamiento y desempeño.

## Trabajo colaborativo

El proyecto fue desarrollado por un equipo de cinco integrantes con diferentes responsabilidades, incluyendo ingeniería de datos, ciencia de datos, visualización mediante Power BI, Scrum Master y Product Owner.

Este repositorio presenta principalmente el trabajo correspondiente a mi participación en el área de **Ciencia de Datos**.
